# Customer Behavior Analysis - Alfido Tech

## 📌 Project Overview
This project analyzes customer transaction data to understand purchasing behavior, spending patterns, and customer segmentation.

## 📊 Dataset
The dataset includes information such as total bill, tip, customer type, day, and time.

## 🔍 Analysis Performed
- Summary statistics (mean, median, mode)
- Missing value analysis
- Data visualization (histogram, bar chart, line chart)
- Customer segmentation

## 📈 Key Insights
- Most customers fall in moderate spending range
- Small group visits are common
- Spending varies across different days

## 💡 Recommendations
- Focus on high-value customers
- Improve engagement for low spenders
- Optimize peak days
- Personalized marketing
- Increase customer engagement
